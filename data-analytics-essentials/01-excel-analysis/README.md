# 📊 Excel Data Analysis & Statistics (Modules 1–5)

This directory contains my hands-on laboratory files, data cleaning sheets, and statistical workbooks for the foundational phase of the Cisco curriculum.

## 📁 Covered Modules & Deliverables
* **Module 1: Data Analytics Projects** — Strategic overviews of descriptive and predictive analytics workflows.
* **Module 2: Data Gathering & Investigation** — Initial data profiling, parsing file types, and baseline data formatting.
* **Module 3: Preparing & Cleaning Data** — Handling null values, parsing unformatted fields, and removing duplicate records.
* **Module 4: Transforming Data with Excel** — Implementation of absolute cell referencing (`$`), conditional logic (`IF` statements), and dynamic cross-table calculations (`VLOOKUP`).
* **Module 5: Statistical Analysis** — Calculation of mean, median, mode, and standard deviation fields paired with descriptive exploratory charting.

## 🛠️ Core Skills Demonstrated
* Dynamic data parsing and cleaning pipelines.
* Multi-criteria data summarization using **Pivot Tables** and **Pivot Charts**.
